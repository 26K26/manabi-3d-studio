# まなび3D Studio

Tinkercad風のブラウザCADと Kiri:Moto を組み合わせた、学校でも利用できる3D設計・スライスツールの試作です。

## 試すには
公開用の `index.html` がリポジトリのルートにあります。GitHub Pagesを有効にすると、iPad・Chromebook・PCのブラウザから同じURLで利用できます。

### GitHub Pagesの初回設定
1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** に設定
3. Branch を **main**、フォルダーを **/(root)** にして **Save**
4. デプロイが完了したら **https://26k26.github.io/manabi-3d-studio/** を開く

以後、index.htmlを更新するたびに同じURLへ反映されます（反映まで時間差があります）。

## 現在の試作機能（v0.4.5）
- 白背景の3D CADと右側図形パレット
- マウス・タッチによる図形のドラッグ配置
- iPadで使える範囲選択モード、複数図形の選択と解除
- 選択した実体の結合・選択した穴による切り抜き（CSG／試験実装）
- 図形のサイズ変更、寸法ラベルの数値編集
- 実体・穴モード、結合／切り抜きの試験実装
- STL保存、編集データ保存・復元
- Kiri:Motoへの転送試験

## 注意点
- **学校や家庭での動作を確認するための開発途中のテスト版**です。
- Kiri:Motoとの連携は外部サイトへの埋め込み通信を使用しており、CAD→Kiri転送の完了は未確認です。
- プリンタープロファイル・スライス結果の実機印刷互換性は未検証です。出力した印刷データを確認せず実機に投入しないでください。
- Three.js・その他のライブラリとKiri:Motoを外部の配信元から読み込むため、現時点ではインターネット接続が必要です。
- CAD再編集用のプロジェクト形式とSTLは別です。STLだけでは結合・穴開けなどの編集履歴は保持されません。

## 今後の目標
CAD→スライサー直接転送の確実な実装、直感的なiPad操作、図形編集機能の品質向上、複数プリンター対応、必要に応じたOpenCascade系CADエンジンの導入。


## v0.4.5 動作テスト手順（iPad／PC）

1. CADで「実体を置く」→「ボックス」を配置。
2. 「穴を置く」→「円柱」を配置。ボックスに少し重ね、高さや位置を数値入力で調整する。
3. 上部の「▧ 範囲選択」をオンにして、**2つの図形を囲む**。右から左へ囲むと部分的に触れた図形も選択できる。左から右へ囲むと全体が入った図形だけを選択できる。図形を1つずつタップして追加・解除することも可能。
4. 「実体1・穴1」と表示されたら「🔗 結合・穴あけ」を押す。
5. 穴図形が消え、ボックスから円柱形状が差し引かれたか確認する。
6. ほかに置いた図形が消えていないか確認する。

**注意**：現状の結合は形状を確定する操作です。個々のプリミティブとパラメトリック編集履歴は統合後のSTLメッシュには残りません。編集前には「編集データ保存」をおすすめします。

CAD→Kiri:Motoの転送とプリンター実機との互換性はまだ未確認です。保存したスライス結果をそのまま印刷しないでください。
